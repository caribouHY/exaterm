ExaTerm

AIエージェント対応ターミナルソフト

SSH、Telnet、シリアル接続に対応した Windows 向けターミナルです。

インストール方法↓

主な機能

{ }AI エージェント連携

ExaTerm が提供する CLI ツールや MCP サーバーを通じて、Claude や Codex などの AI エージェントが端末を自動操作できます。

>_接続プロファイル

よく使う SSH や Telnet の接続先を保存し、プロファイル名を選んで接続できます。

≡表示とログ

機器に合わせて端末出力を色分けします。セッションログは手動または自動で保存できます。

インストール

Windows の PowerShell で実行します。

winget install caribouhy.ExaTerm

インストーラーは GitHub Releases から入手できます。
