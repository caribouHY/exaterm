コントリビューター向けドキュメントには、現在のコード構成と長期的な設計判断を記載します。エージェントが作業時に実行する手順は、`.agents/skills/` 配下のリポジトリ固有 Skill に配置します。

ユーザー向けガイドは英語・日本語で管理します。変更頻度の高い技術情報の同期ずれを避けるため、コントリビューター向けドキュメント、アーキテクチャ、設計判断は英語を正本とします。
