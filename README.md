# ExaTerm

SSH and Serial communication terminal with AI assistant.

## Features

- SSH and Serial communication
  - Multiple tabs
- AI assistant
  - OpenAI
  - Anthropic
  - Gemini
  - Ollama

## Getting Started

### Prerequisites

- Rust
- Node.js

### Installation

1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `cargo run` to start the application
